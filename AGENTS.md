# Repository instructions

## Issue-first development

- Do not change code, tests, scripts, workflows, configuration, or other executable behavior without an existing GitHub issue.
- When work is identified, create the issue before editing code.
- Create issues in `jcszymansk/claude-review-loop`, this fork, not the upstream repository.
- Include the issue number or URL in the change context before implementation starts.
- This policy applies to every agent and contributor working in this repository.

Documentation-only changes and updates to this policy do not require a separate issue unless they also change executable behavior.
